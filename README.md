# B.I.G. Seller Studio

Kel's multi-channel seller studio — the companion to Mirra's Vinted Seller Studio, in B.I.G. Steppas colors (charcoal, gold, coral on warm white).

Tracks daily sales across **Vinted and Depop**:

- **Monthly goal** is the headline (charcoal hero card), weekly goal underneath — both editable inline, with smooth animated bars and a gold glow when a goal is hit
- **Channel filter chips** (All channels / Vinted / Depop) rescope the whole Home board
- **Weekly breakdown** — bars fill toward the daily goal (editable from the small link at the bottom of the card); tap any day to edit that day's sales per channel
- **Quick daily entry** — pick the channel, enter today's sales, get a 💰👑✨ burst
- **Weeks** history, **Insights** (all-time totals, goals reached, best week/day, by-channel totals, weekly chart, monthly totals, money day)
- **Settings** holds only the Danger Zone — goals are edited right on Home

Single self-contained `index.html` (no build step, no dependencies). Data is stored per-device in the browser's local storage and never leaves the phone.

Hosted with GitHub Pages from this repo.
